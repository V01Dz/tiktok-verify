Política de Privacidade — Sistema Local

O "Sistema Local" roda inteiramente no computador do próprio dono. Nenhum dado é enviado a servidores de terceiros além das plataformas que o dono conecta de propósito (TikTok, YouTube, e provedores de IA usados para gerar os vídeos).

Quando você conecta sua conta do TikTok, o programa usa o token de acesso apenas para enviar os vídeos que o próprio dono produziu para a caixa de rascunhos da própria conta dele. O programa não lê, não coleta e não armazena dados de outros usuários do TikTok. O token de acesso fica guardado de forma criptografada no Gerenciador de Credenciais do Windows do computador do dono, e nunca é compartilhado com mais ninguém.

Você pode revogar o acesso a qualquer momento em tiktok.com/setting/manage-account ou desconectando dentro do próprio programa.
